# Модульный фреймворк автоматизации тестирования для интернет-магазина Pas Normal Studios

## 📝 Описание проекта
Данный проект представляет собой высокоуровневый автоматизированный фреймворк для сквозного (End-to-End) тестирования функционала международного интернет-магазина премиальной велоодежды `pas-normal-studios.com`. Архитектура спроектирована на языке **Java 21** с использованием объектно-ориентированного подхода **POM (Page Object Model)** в соответствии со стандартами проектирования тестовых систем **ISTQB** и принципами чистого кода **SOLID**.

## 🛠 Технологический стек
* **Язык программирования:** Java 21
* **Тестовая платформа:** JUnit 5 (v5.11.0)
* **Автоматизация UI:** Selenium WebDriver (v4.22.0)
* **Автоматизация API:** Rest-Assured (v5.4.0)
* **Генерация тестовых данных:** Net-Datafaker (v2.4.2)
* **Управление зависимостями:** Maven
* **Тестовая отчетность:** Allure Framework (v2.28.0)
* **Логирование:** Log4j2 (v2.23.1)

## 🏗 Архитектура проекта и паттерны проектирования
Фреймворк разделен на независимые архитектурные слои согласно принципу **Single Responsibility (SRP)**, что гарантирует масштабируемость системы и чистоту кода:

1. **Слой управления сессией браузера (`com.pasnormalstudios.driver`):**
    * **Singleton Pattern (`Driver.java`)** — гарантирует существование строго одного инстанса `WebDriver` (ChromeDriver) на протяжении выполнения теста, изолируя сессии и предотвращая утечки памяти.

2. **Инфраструктурный слой страниц (`com.pasnormalstudios.pages`):**
    * `BasePage.java` — аккумулирует базовую конфигурацию страниц, содержит защищенный логгер `Logger log` и инициализирует явные ожидания `WebDriverWait` для безопасного взаимодействия с веб-элементами.

3. **Бизнес-слой страниц (`com.pasnormalstudios.pages`):**
    * `HomePage.java` — инкапсулирует стартовую логику, управление куками (`clickAllowCookiesButton`) и переход к профилю.
    * `AccountPage.java` — инкапсулирует локаторы (XPath) форм авторизации/регистрации и предоставляет верхнеуровневые бизнес-методы взаимодействия (например, `setEmailPasswordAndClickLoginButton`).
    * `ResetPasswordPage.java` — изолирует логику и элементы формы сброса пароля.

4. **Слой тестовых данных (`com.pasnormalstudios.data`):**
    * **Factory Pattern (`Users.java`)** — фабрика для динамической генерации тестовых сущностей пользователей (`getRandomUser`) с использованием библиотеки Datafaker.

## 📊 Тестовое покрытие

### 💻 UI Тестирование (`com.pasnormalstudios.ui`)
* **`AccountTest.java`**: Комплексные UI-тесты аутентификации, регистрации и проверки валидационных сообщений (`getEmailAlertMessageText`, `getPasswordAlertMessageText`) при работе с некорректными данными.
* **`ResetPasswordTest.java`**: Валидация логики восстановления доступа и сброса пароля.

### 🔌 API Тестирование (`com.pasnormalstudios.api`)
* **`AccountTest.java`**: Тесты интеграции и валидации бэкенд-эндпоинтов аутентификации. Тесты используют слой `ApiService` на базе Rest-Assured для отправки изолированных POST-запросов и проверки статус-кодов.

## 📈 Логирование и Тестовая отчетность
* **Allure Framework:** Полная интеграция с JUnit 5 (`allure-junit5`). Отчеты предоставляют пошаговую детализацию прохождения UI и API тестов.
* **Log4j2 (Конфигурация `log4j2.xml`):** Настроено прозрачное логирование действий. Логи пишутся одновременно в консоль (`Console Appender`) и в файл (`File Appender` по пути `logs/app.log`).
* **Логирование API-трафика:** В `ApiService` реализованы фильтры (`RequestLoggingFilter` / `ResponseLoggingFilter`), которые автоматически перехватывают и форматируют детали HTTP-запросов и ответов напрямую в лог приложения.

## 🚀 Команды для запуска

Запуск всех тестов проекта (UI и API тестов) с автоматическим сбором результатов Allure:
```bash
mvn clean test
```
